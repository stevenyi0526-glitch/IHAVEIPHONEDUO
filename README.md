# IHAVEIPHONEDUO

我也有 iPhone Duo：上传任意图片，一键变成 iPhone Duo 外屏截图的样子，自带右侧黑边。

iPhone Duo 的外屏截图会带上右侧的黑色状态栏，去不掉，再截一次还会“套娃”。外屏又短又宽，这种截图发到普通手机上全屏查看时，上下还会多出一大片黑色。既然去不掉，不如人人都有一条。

<img src="docs/example.png" alt="效果示例：图片变成贴左、右侧圆角的窗口，右侧是带时间和电量的黑边，上下是大片黑色" width="320">

## 使用方法

1. 点击「上传图片」，选择一张图片。
2. 查看生成的效果。
3. 点击「保存图片」，得到一张 1206×2622 的 PNG。

把生成的图片再上传一次，就能得到“套娃”效果。

图片只在浏览器本地处理，不会上传到任何服务器。

## 效果说明

- 输出是普通手机的屏幕比例（1206×2622），中间是按 1398×2034 外屏分辨率绘制的截图，上下是黑色。
- 图片贴左显示在窗口内，不会被裁剪。比例不同时，上下或右侧会多出黑边。
- 右侧状态栏里的时间是当前时间，电量（88）是固定的。
- 布局按真实的外屏截图测量，不同 App 或状态下可能略有差异。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
./start.sh
```

脚本会在首次运行时安装依赖，然后启动开发服务器。

构建生产版本：

```bash
npm run build
```

产物在 `dist/` 目录，可以部署到任意静态托管服务。

## 技术栈

Vite + React，图片用 Canvas 绘制，核心逻辑在 [`src/duoFrame.js`](src/duoFrame.js)。
